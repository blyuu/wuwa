# 적 전투 AI 디테일 (공격 추적 · 확률 회피 · 포이즈)

## 왜 필요했나
적이 공격을 그냥 정해진 방향으로만 내지르거나, 맞을 때마다 매번 경직되면 전투가 심심하고 스턴락이 걸립니다.

## 무엇을 설계했나
- **공격 추적** — 공격 어빌리티가 도는 동안 플레이어를 향해 조준하고, 어빌리티가 끝날 때 추적을 멈춥니다. 회피 여지는 타격 시점에 루트모션 방향이 커밋되는 것으로 확보합니다.
- **확률 회피** — 맞을 때 일정 확률로 백스텝으로 피함
- **포이즈** — 피격 리액션을 일정 확률로만 재생해 스턴락 방지

## 어떻게 설계했나
`GA_EnemyAttack`이 시작될 때 `SetAttackTracking(true)`, 끝날 때(`EndAbility`) `false`로 둡니다. 추적이 켜진 동안 매 틱 플레이어 쪽으로 yaw를 보간하고, 모션 워핑 `AttackTarget`을 매 틱 플레이어 위치로 갱신해 루트모션 공격이 플레이어를 호밍합니다. **히트가 나도 추적을 끄지 않습니다** — 다단 히트 공격이 스윙 내내 플레이어를 따라가도록 하기 위함이고, 추적 종료는 어빌리티 종료 시점입니다. 추적을 켜는 동안만 `bOrientRotationToMovement`를 껐다가 끝나면 복원해, 이동 회전이 공격 조준과 싸우지 않게 했습니다(이게 "공격이 그냥 직진하던" 문제의 실제 해결책입니다).

확률 회피는 플레이어의 히트가 데미지를 적용하기 **직전**에 적이 굴려서, 성공하면 백스텝 몽타주를 재생하고 그 히트를 완전히 무효화합니다(데미지·그로기·게이지 전부 없음). 이 회피 게이트는 `GA_BaseAttack`과 `GA_ResonanceSkill`의 히트 처리 **양쪽 모두**에 있어, 어떤 플레이어 공격이든 일관되게 적용됩니다. 피격 리액션(포이즈)은 `HitReactChance`(기본 0.3)로 굴려 약 70%는 경직 없이 버티게 했습니다. 모든 수치는 데이터 에셋에서 적별로 조절됩니다.

```cpp
// 플레이어 히트가 데미지 적용 직전에 물어본다 (GA_BaseAttack / GA_ResonanceSkill 공통)
if (AEnemyCharacter* E = Cast<AEnemyCharacter>(HitActor))
    if (E->TryDodge()) return;      // 회피 성공 -> 이 히트는 데미지·그로기·게이지 전부 무효

// 적은 일부 확률로만 흔들린다 (스턴락 방지)
void AEnemyCharacter::PlayHitReact()
{
    if (EnemyDataAsset && FMath::FRand() > EnemyDataAsset->HitReactChance) return;
    Super::PlayHitReact();
}
```

**왜 이렇게 나눴나** — 회피를 "데미지 적용 직전"에 두면 성공 시 데미지·그로기·게이지·피드백이 통째로 없던 일이 되어(01의 파이프라인을 아예 안 탐) 처리가 단순합니다. 포이즈를 확률로 둔 이유는, 매 히트마다 경직시키면 스턴락으로 무한 콤보가 나기 때문입니다.
