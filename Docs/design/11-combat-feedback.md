# 전투 피드백 (타격음 · 스킬/피격 보이스)

## 왜 필요했나
타격음이나 보이스는 타격감의 큰 부분인데, 이걸 **모든 공격 몽타주마다 AnimNotify로 일일이 다는 것은 비효율적**입니다.

## 무엇을 설계했나
타격음은 노티 없이 모든 공격에 자동 적용되고, 보이스는 필요한 곳에만 붙는 구조입니다.

## 어떻게 설계했나
- **타격음** — 데미지 일원화 지점에서 재생합니다(플레이어가 적을 때려 피해가 0보다 클 때마다). 모든 공격이 이 지점을 지나므로 노티가 필요 없고, 적이 회피하면(히트 무효) 이 지점 자체를 지나지 않아 소리도 안 납니다. 사운드는 적 데이터 에셋에 두어 적별로 다른 타격감을 줄 수 있습니다.
- **스킬 보이스** — 정확한 프레임에 맞추기 위해 `Event.Skill.Voice`를 쏘는 범용 노티로 처리합니다(스킬 데이터의 보이스 목록에서 랜덤 재생).
- **피격 음성** — 피격 리액션과 같은 지점(`PlayHitReact`)에서 랜덤 재생합니다. 몽타주가 없어도 음성은 나옵니다. 다만 **적은 포이즈(경직) 판정을 통과해 실제로 흔들릴 때만** 음성이 납니다 — `HitReactChance` 굴림에 실패하면 `Super::PlayHitReact` 이전에 early-return하므로, "타격음(매 확정 히트)"과 "적 피격 음성(경직 시)"은 발동 게이트가 다릅니다.

소스는 가상 함수 `GetHitVoiceLines()`로 갈라, 플레이어(playable)는 데이터 에셋에서, 적은 BP에 세팅된 폴백 목록에서 읽습니다 — **플레이어=데이터 주도, 적=폴백** 구조입니다.

```cpp
// 타격음: 데미지가 지나는 공통 지점에서 재생 (노티 불필요)
if (AEnemyCharacter* Enemy = Cast<AEnemyCharacter>(TargetActor))
    if (Enemy->EnemyDataAsset && Enemy->EnemyDataAsset->HitSound)
        UGameplayStatics::PlaySoundAtLocation(Enemy, Enemy->EnemyDataAsset->HitSound,
                                              Enemy->GetActorLocation());
```

**왜 일원화 지점에서였나** — 타격음을 공격 몽타주마다 노티로 달면 공격이 늘 때마다 손이 가고, "회피하면 소리 안 나게"까지 각 노티에서 챙겨야 합니다. 데미지가 지나는 공통 지점에서 한 번만 재생하면 새 공격에 자동 적용되고, 회피로 히트가 무효화되면 이 지점을 안 지나 소리도 저절로 안 납니다.
